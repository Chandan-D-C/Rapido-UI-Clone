# Rapido UI Clone 🛵

A frontend recreation of the Rapido website built using **HTML and CSS**. This project focuses on recreating the look and feel of Rapido's website with a clean layout, modern styling, and multiple sections.

## 🚀 Overview

This project is a UI clone of the Rapido ride-hailing website. It showcases a visually appealing landing page with different sections highlighting ride-booking options, services, offers, and other features.

## ✨ Features

- **Navigation Bar** – Includes Home, About Us, Safety, Careers, Blog, Press, and Contact links.
- **Hero Section** – Features the main heading, ride-booking inputs, and banner image.
- **Our Services** – Displays different services such as Bike Taxi, Auto, Cab, Parcel, Travel & Stay, and Metro.
- **What We Offer** – Highlights Quick Pickup, Best Fares, and Never Too Far.
- **Earn with Rapido** – Promotes earning opportunities for Rapido Captains.
- **Download Section** – Showcases the customer and captain applications.
- **Footer Section** – Includes navigation links, app download options, and social media icons.
- **Hover Effects** – Interactive styling for buttons, service cards, and links.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Noto Sans)
- Font Awesome Icons

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/rapido-ui-clone.git
   ```

2. Navigate to the project folder:

   ```bash
   cd rapido-ui-clone
   ```

3. Open `rapido.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code.
